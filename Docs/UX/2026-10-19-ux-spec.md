# UX spec, round of 2026-10-19

Covers §1 of `Docs/Plans/2026-10-19-round.md`, numbered the same way (developers cite "UX §1.4"). Everything here
is UI Toolkit (`Assets/CasinoMares/UI/*.uxml`, `Common.uss`) plus camera/post values. No new art files.

## 0. Shared notes (read once)

- **Theme tokens** (`Common.uss :root`): `--cm-gold` rgb(232,186,98), `--cm-gold-dark` rgb(176,130,58), `--cm-text`
  rgb(245,236,222), `--cm-text-dim` rgb(190,176,160), `--cm-danger` rgb(222,104,96), `--cm-bg-soft`
  rgba(28,18,24,0.7), `--cm-border` rgb(120,84,52). **Add one token:** `--cm-wine: rgb(140, 28, 56);` (used by §1.1,
  §1.2, §1.5).
- **Layouts.** Desktop UI is 1080 px tall. Touch (`Platform.IsTouch`) scales to ~560 UI px tall; every document root
  gets class `touch`; `KeyHints.Strip` removes " (Space)" / " (X)" from button labels written in UXML, and labels set
  at runtime must use `KeyHints.For("Space")`. Table corner buttons (`.bj-corner`) sit bottom-right on desktop and
  top-right (`top: 82px`) on touch; toasts sit at `top: 80px` desktop / `150px` touch; the touch pills (Menu, Chat, Top
  cats) are top-left at `top: 82px`. Bottom centre (`.bj-bottom`) is the table panel.
- **Touch targets:** every new button uses `.bj-button` (46 px tall, min-width 96) or `.touch-*` sizes ≥ 44 px.
- **Pause menu** is in `Hud.uxml` (`pause-root`) and `HudController.cs`, not `MainMenuController` (that's the title
  menu). New toggles follow `follow-toggle`: a `ui:Toggle` with class `pause-toggle`, value read into a PlayerPrefs
  int, `PlayerPrefs.Save()` happens on resume already.
- **Toasts:** `Toasts.Show(text)`; 4 s, fade over the last 0.6 s, notify sound. Copy is one sentence, ends with a
  period or an exclamation mark, no emoji (the UI font has none).
- **Chat lines** (`PlayerCat.Announce`) are third person: `"<name> ordered a glass of wine."`.

## 1.1 Drunk effect (what the drunk player sees)

### Tiers and the one-knob design

One runtime `VolumeProfile` holds the **5+ glass** values below; the drink count only sets the **volume weight** and
the Cinemachine **noise amplitude gain**, so every value scales together and ramps are a single float:

| Glasses | Tier name | Volume weight / noise gain |
|---|---|---|
| 0–2 | sober | 0 (component disabled, volume weight 0, noise amplitude 0) |
| 3 | tipsy | 0.5 |
| 4 | drunk | 0.75 |
| 5+ | very drunk | 1.0 |

### Post-processing (the tipsy `Volume`, priority above the scene volume, global)

Values at weight 1.0; the base scene profile shows through at lower weights (classic hall: vignette 0.3, saturation
+6; sea: vignette 0.2, saturation +18).

| Component | Override | Full value (weight 1) | At 0.5 (3 glasses) |
|---|---|---|---|
| `LensDistortion` | intensity | magnitude **0.22**, the sign that bulges the centre outward (fisheye); check once in the editor | 0.11 |
| | scale | **1.06** (hides the bent edges) | 1.03 |
| | xMultiplier / yMultiplier | 1 / 1 | |
| `ChromaticAberration` | intensity | **0.45** | 0.22 |
| `ColorAdjustments` | saturation | **+22** | (base + 22) / 2 |
| | postExposure, contrast, hue | not overridden | |
| `Vignette` | intensity | **0.5** | blends from the scene's 0.3 / 0.2 |
| | smoothness | **0.6** | |
| | color | rgb(30, 8, 16) (near-black wine) | |
| `Bloom` (optional, nice) | intensity | 1.2 (base 0.75 / 0.9), scatter 0.8 | |

Nothing else. No DepthOfField, no MotionBlur (both cost a pass and both make people sick).

### Camera sway (`CinemachineBasicMultiChannelPerlin`)

On the follow camera and on whichever seat/override camera is current (add the component on first use, cache it; the
camera's transform set by `PlayerCameraRig` and the noise compose, Cinemachine applies noise after). A runtime
`NoiseSettings` (`ScriptableObject.CreateInstance`) with **orientation channels only**, no position channels (position
noise clips into chairs and walls):

| Channel | Amplitude (deg, at gain 1) | Frequency (Hz) |
|---|---|---|
| X (pitch) | 0.5 | 0.17 |
| Y (yaw) | 0.8 | 0.12 |
| Z (roll) | 1.5 | 0.09 |

Periods of ~6, ~8 and ~11 s so the three never line up; all ≤ 0.5 Hz. `FrequencyGain` 1 always; `AmplitudeGain` =
tier gain × ramp. Nothing in the sway exceeds ±1.5°. While a focus camera (roulette wheel) is up, the noise stays on
the seat camera only; the focus camera gets none.

### Ramps (smoothstep on the single ramp float)

| Event | Duration |
|---|---|
| Becoming drunk (3rd glass) | 3.0 s in |
| Tier change (4th, 5th glass) | 3.0 s to the new tier |
| Sobering (drops below 3) | 6.0 s out |
| "Tipsy visuals" toggled off | 1.0 s out |
| Toggled on while drunk | 3.0 s in |
| Reload / leave / stand up | no change (state follows `DrinkCount`; standing up only swaps which camera carries the noise) |

Mobile: identical values. The effect is one extra volume blend inside URP's uber pass, nothing on the 30 fps budget.

### Pause-menu toggle

`Hud.uxml`, pause panel, directly after `follow-toggle`:

```xml
<ui:Toggle name="tipsy-toggle" label="Tipsy visuals" class="pause-toggle" />
```

PlayerPrefs key `TipsyVisuals` (int, default 1). Off: volume weight 0 and noise gain 0 (ramped as above); the HUD
indicator, toasts, the wobble-free two-total labels (§1.2) and the bonus (§1.3) stay. `HudController.SetPaused(true)`
sets the toggle from the pref like `_follow`.

## 1.2 Drunk blackjack totals

For the local player's own hands while `IsDrunk`, in `TableOverlay.LabelTable`:

- **Text:** `$"{first} or {second}?"` → "17 or 21?". Plain numbers only; never "Soft". The order comes from the hash
  (plan §4), so the real total is first about half the time.
- **Bust** hands: "Bust" exactly as today. **Settled** hands (`outcome != None`): real total and outcome as today
  (`"{total} · Win"`), so the result is always honest.
- **Class:** add `hand-label--tipsy` after `Place()` (which resets the class list each frame), alongside the existing
  modifiers; `--active`, `--win/--lose/--push` keep their meaning.

```css
.hand-label--tipsy { background-color: rgba(90, 24, 48, 0.82); -unity-font-style: bold-and-italic; }
```

- **Wobble** (only while "Tipsy visuals" is on): `label.style.rotate = new Rotate(angle)` with
  `angle = 3° × sin(2π × 0.25 Hz × Time.time + seat × 1.7 + hand × 0.9)`. No scale, no translate. Reset `rotate` to
  0 on every other label (set it in `Place()` to be safe; it's one style write per label per frame, which
  `LateUpdate` already does for position).
- **Untouched:** the dealer label (`"Dealer 17"`), other players' labels, the spectator panel, the settlement labels
  and the HUD phase text (`"Your turn: Soft 17"`). See the open question at the end about the phase text.

## 1.3 Tipsy bonus

- On a net win while drunk, bonus `b = max(1, floor(net × rate))`, with the rate by game (`TipsyBonus.RateFor`):

  | Game | Rate |
  |---|---|
  | Blackjack | 0.20 |
  | Poker (pots won) | 0.10 |
  | Baccarat, roulette, slots | 0 (no bonus, no toast) |

- Show it with the existing gain label by raising `ChipRewards.Earned(b, big: false)` (the HUD then animates
  `balance-gain` "+b" with the coin sound; a reward in the same moment adds into the same label, that's fine). No new
  element.
- Toast, after the table's own result toast (subscribe to the result event after the HUD does, or delay by one frame):
  **"Tipsy bonus! +{b:N0} chips on top."**
- No chat line; no bonus on pushes or losses; the balance label updates through `ProfileStore` as usual.

### Tipsy meter (`bar-count` over `bar-meter-track`)

At the bar only, left of the Order button: a label over a track of five segments, one per glass still in effect
(`PlayerCat.Local.DrinkCount`), built by `TerraceHud`. The meter is full at 5 glasses (`TipsyEffect.VeryDrunkAt`),
the point where the drunk effect is at full weight, so a full meter means the full effect.

- Label: "Sober" (0), "1 glass", "2 glasses", "Tipsy" (3), "Drunk" (4), "Very drunk" (5+); gold and bold
  (`bar-count--tipsy`) from 3.
- Segments: empty `rgba(255,255,255,0.1)`, filled `--cm-wine`; the 3rd to 5th (the tipsy zone) fill brighter
  (rgb(196,52,88)) and sit after a 6 px gap that marks where tipsy starts. Fills fade in over 0.4 s.
- Full (5+): the track's border turns gold (`bar-meter--full`).
- Glasses expire one by one (6 min each), so the meter drops a segment at a time. The HUD pips (§1.1) show the same
  count everywhere; the meter is the readable version at the bar.

## 1.10 Top cats leaderboard (chips earned this session)

Ranks every cat in the room by **net chips earned since it joined this room**: game wins minus losses, plus paw
rewards; the hourly welfare refill doesn't count. Sorted descending. Same ranking and colours on the HUD panel
(Tab / the "Top cats" pill) and on the in-world wall board.

- **Desktop:** right side, top 90, 360 px. Podium (top 3), rows from 4th down to 10th, then the local cat pinned.
- **Phone (landscape, ~560 px short side):** top 140, 340 px, at most 300 px tall: podium, rows 4th to 6th, then the
  local cat pinned.
- **Podium:** three fixed cards in `Hud.uxml`, laid out 2nd, 1st, 3rd; 1st is taller, gold-bordered and crowned.
  Each card: swatch (fur colour, 28 px), name (ellipsis), net. A place with no cat is dimmed (`lb-podium--empty`).
- **Net:** "+1,240" in gold (`lb-net--pos`), "-80" in `--cm-wine-text` rgb(222, 96, 124) (`lb-net--neg`),
  "0" dim (no class). Plain hyphen for the minus (the UI font has no U+2212).
- **Rank change:** an up (gold) or down (wine) arrow beside the rank for 3 s after the cat's rank changes.
- **You:** gold left edge and soft gold fill, name followed by " (you)". When you're outside the shown rows, a "···"
  gap and your row are pinned at the bottom.
- **Empty** (every net is 0): podium and rows hidden, "Earn your first chips" / "Win a hand, paw a patron or top the
  cat wall."
- **Nameplate crown:** the #1 cat, while its net is above 0, gets a crown above its nameplate and a gold name and
  outline. The local cat has no nameplate, so it sees its own lead on the board only.
